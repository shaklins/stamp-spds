# Шаблон текстовой части проектов по СПДС

Это шаблон текстовой части проектной документации, выполненной в соответствии с системой СПДС (Система проектной документации для строительства). Шаблон предназначен для быстрой сборки стандартных документов.

> [!WARNING]
> Пакет находится в разработке, функционал может измениться в любой момент.

## Структура проекта

### Папка `content/` — основные документы

| Файл | Назначение |
|---|---|
| `general-data.typ` | Общие данные (`ОД`) — основные указания, исходные данные |
| `explanatory-note.typ` | Пояснительная записка (`ПЗ`) |
| `equipment-spec.typ` | Спецификация оборудования (`СО`) |
| `cable-journal.typ` | Кабельный журнал (`КЖ`) — форма 1 |
| `title-page.typ` | Титульный лист / обложка проекта |
| `drawing-list.typ` | Ведомость рабочих чертежей основного комплекта (`ЭЧ`, `.ОД`, `.ПЗ`) |
| `reference-docs.typ` | Ведомость ссылочных и прилагаемых документов (`.КЖ`, `.СО`, ГОСТы) |

### Папка `template/` — шаблоны оформления

| Файл | Назначение |
|---|---|
| `template.typ` | Основной шаблон страницы СПДС (формы 3, 4, 5, 6) |
| `frame.typ` | Рамка документа |
| `tables-spds.typ` | Таблицы форм СПДС |
| `tables-eskd.typ` | Таблицы форм ЕСКД |
| `place.typ` | Утилита размещения элементов |

### Папка `config/`

| Файл | Назначение |
|---|---|
| `data_stamp.typ` | Данные штампа (организация, авторы, шифр) |
| `logo.jpg` | Логотип для титульного листа |

## Компиляция

Для сборки проекта используйте флаг `--root`, указывающий корень проекта:

```bash
typst compile --root . file.typ
```

Это необходимо для корректного разрешения относительных путей (`#include`, `#import`, пути к изображениям) в файлах `content/` и `template/`.
